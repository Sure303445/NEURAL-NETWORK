# CAREAI

CAREAI is an AI-powered medical diagnosis system that analyzes chest X-ray images to detect Tuberculosis (TB) and Pneumonia using deep learning. The application provides accurate predictions with explainable AI visualizations to assist healthcare professionals and students.

## Features

- Chest X-ray image classification
- Tuberculosis detection
- Pneumonia detection
- Normal case identification
- Explainable AI using Grad-CAM
- Interactive Streamlit web application
- Fast and accurate predictions
- User-friendly interface

## Technologies Used

- Python
- TensorFlow
- Keras
- MobileNetV2
- OpenCV
- NumPy
- Pandas
- Matplotlib
- Streamlit

## Deep Learning Model

- Transfer Learning using MobileNetV2
- Image preprocessing
- Data augmentation
- Softmax classification
- Grad-CAM visualization

## Dataset

The model is trained on publicly available chest X-ray datasets containing:

- Tuberculosis (TB)
- Pneumonia
- Normal chest X-rays
